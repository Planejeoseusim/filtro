dúvidas frequentes

Perguntas frequentes

Separei as principais dúvidas para facilitar a decisão antes de encomendar seu convite.

Quem envia os links dos botões interativos?

O cliente envia os links. Você pode mandar link de localização, formulário de confirmação, lista de presentes, manual dos convidados ou qualquer link que queira usar no convite.

O convite já vai pronto para enviar?

Sim. Você recebe o arquivo final pronto para compartilhar com os convidados pelo WhatsApp.

Posso personalizar com as cores do casamento?

Sim. O convite pode seguir a identidade do casal, incluindo paleta de cores, estilo visual, nomes, data, horário, fotos e textos.

Qual a diferença do Estendido?

O Estendido funciona como uma página vertical do casamento. Ele comporta mais fotos, mais informações e até 5 botões de funcionalidades, deixando a experiência mais completa.

Tem alteração inclusa?

Sim. A página já considera uma rodada de revisão para ajustes simples após a primeira prévia.
